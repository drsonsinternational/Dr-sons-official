## 🏢 About DrSons International

**DrSons International** is a premier food processing and commercial manufacturing enterprise specializing in agricultural produce, commercial beverages, ice cream, and specialty food products. Built on a foundation of rigorous quality assurance, modern cold-chain infrastructure, and sustainable farm sourcing, DrSons International caters to wholesale partners, commercial brands, and institutional food service clients globally.

| Vertical | Focus Areas | Key Capabilities |

## 🚀 Local Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- `npm` (bundled with Node.js)

### Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/drsonsinternational/Dr-sons-official.git
   cd Dr-sons-official
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment variables (optional):**
   ```bash
   cp .env.example .env.local
   ```

4. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:3000`.

5. **Build for production:**
   ```bash
   npm run build
   ```
